# 📱 Lost & Found Portal

A simple **web-based Lost & Found system** built using **HTML, CSS, and JavaScript**.  
This project helps users report lost items and browse found items easily.

---

## 🚀 Features

- 🔍 Search items
- ➕ Report Lost Items
- 📦 Report Found Items
- 📄 View all reports
- 💾 Data stored using **localStorage** (no backend required)
- 📱 Fully responsive (mobile-friendly UI)
- 🧭 Multi-page navigation

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Browser LocalStorage
